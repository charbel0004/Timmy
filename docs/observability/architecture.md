# Architecture audit and implementation map

- React 19, Vite 7, TypeScript, Tailwind 4 plus shared CSS; hash navigation and component state; fetch cookie sessions and CSRF. Existing Markdown renderer, Lucide icons, no graph or animation library.
- main.tsx supplies shell/permission navigation; assistant.tsx conversation/history/upload/mapping/voice; features.tsx overview/imports/timesheets/discrepancies/payments/settings; workspace/iam provide activities/projects/RBAC. Financial adapters that are not implemented remain blocked.
- FastAPI timmy.main registers operational, documents, workflows, chat, IAM, policy and voice routers. Chat POST returns a complete structured reply; existing activity endpoint polls an in-memory bounded string trail. No token stream exists to preserve. New SSE streams observable execution events, not fabricated response tokens.
- OllamaAdapter.structured calls loopback /api/chat with stream=false, think=false, temperature=0, a seed, bounded num_predict and JSON schema. Existing adapter discards usage; instrumentation now reads supported counters from the actual response.
- Python callbacks and guarded LangGraph execute_graph are the runtime tool boundary. No connected MCP client/registry exists; no MCP calls can truthfully be shown. Compiler notes are not runtime context. Instruction pack is Git pinned and integrity checked.
- SQLite/SQLAlchemy and Alembic (0018 baseline); immutable WorkflowStepReceipt and deterministic Decimal financial services remain authoritative. Telemetry has a separate additive run/event schema, not a replacement for business receipts.
- Principal.require and effective_access enforce global grants and project membership/overrides. Traces are actor-private, with current project permission rechecks on every read and stream batch.
- GitHub CI tests disposable databases/builds; Ubuntu systemd slots, Nginx and a SHA-verified deployer preserve Ollama as an existing loopback service. Automatic migration allowlist is pinned to an older revision; 0019 requires an operator-reviewed schema rollout. No production deployment/restart is part of this task.

Telemetry uses OTel-compatible trace/span identifiers, parent links and timestamps; it is not an OTLP exporter. Ordered events store span transitions, usage, policy metadata and sampled resources. A bounded process buffer bridges SQLite business write locks, with short-timeout background persistence. Telemetry failures never commit/rollback business transactions. A crash can lose the unflushed tail; expired collector heartbeats become interrupted after a 15-minute lease, without immediately misclassifying healthy overlapping slots.
